### 💻 Technical Architecture & Features

- **No Build Step Required**: Clean HTML5, Tailwind CSS, FontAwesome 6, and Vanilla JavaScript.
- **Dynamic OPD Status Clock**: Calculates in real-time whether the OPD is currently open or on break, with live indicators.
- **Interactive Appointment Booking**:
  - Doctor & Department selection
  - Preferred Date & OPD Slot picker
  - Direct WhatsApp integration (pre-populates appointment request for one-click chat with +91 98793 34364)
  - On-screen confirmation modal with reference number
- **Direct Click-to-Call & Clipboard Utilities**: One-tap phone calling and address copying.
- **Full Accessibility (WCAG compliant)**: High contrast, semantic headings, ARIA attributes.
- **Mobile Responsive**: Custom hamburger drawer, responsive layouts, floating emergency action speed dials.
